# 输入数据

- `raw/`：只读原始地图等，不存处理结果，默认不加入Git。
- `processed/`：由脚本生成的二值地图、多尺度连通图等；记录其原始输入和生成命令。
- 用户论文路径记录在被忽略的`docs/source_local.json`；仓库仅记录来源与哈希，不重复复制或上传PDF。

每份数据记录来源/标识符、获取日期、许可、文件哈希、尺寸、坐标轴与单位、尺度换算和处理步骤。教学地图必须标注“合成教学地图”，不能标记为论文长滩港地图。

当前教学地图直接存放在`configs/s1_teaching_map.json`中，没有外部港口数据文件。论文截图可作方法阅读依据，未经比例和障碍标定不能当作原始港口地图。

2026-10-30已加入真实GSHHG2.3.7数据工作流：`scripts/download_gshhg.py`核对官方SHA后下载到raw；`scripts/build_gshhg_maps.py`在新的outputs目录保存填陆粗细图、来源、配置与哈希。原始压缩包、地图数组及源文仍不入Git，只同步生成图和来源元数据。
