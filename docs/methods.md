# 方法与适用范围

本仓库包含韩旭博士论文第三章相关方法的独立学习实现，以及真实海图上的二维 USV/UUV 覆盖规划实验。实现、工程补充与原论文条件分别说明；本仓库不是作者官方代码，未完成原图、原表的严格数值复现。

<a id="scope"></a>
## 输入与模型

- 合成港口示例用于运行与算法教学，不是论文港口原始数据。
- 论文港口实验由图像恢复地图，保留三种阈值敏感性；地图恢复不等于获得作者原始地图。
- 开放海图实验使用固定版本 NOAA ENC，区分覆盖目标与可通行导航水域，实体障碍裕度为 50 m。
- 覆盖足迹为理想 50 m 半径水平圆；普通转场与等待不扫描，明确补扫窗口单列。海图水深分区不等于连续三维海底。
- USV/UUV 协同实验采用二维点平台、前进曲线、启停速度和理想等待；水平几何支援范围不代表实际声学链路可用性。

## 坐标与连续时间核查

坐标内核明确区分东／北方向、米／格与角度单位，并与 PROJ 独立比较。参数和来源见 [坐标来源](r8_coordinate_sources.json)。

曲线时钟按加速、匀速与减速的弧长积分求位置，保留段间与结束后等待。连续距离核查用区间内累计行进弧长外包相对位移，保存极值见证和外侧界；回放帧与绘图采样只用于展示。0.05 m 极值区间宽度是数值要求，不是实际定位或控制精度。

多段前进曲线在原语接头停稳，检查位置与航向连续（G1）及个体速度／加速度约束；这不构成真实艇体动力学或闭环跟踪证明。

## 实验解释

- 覆盖率使用完整固定目标作分母，保留漏扫、孔洞和不可达扫描中心；不以删任务或缩目标达标。
- 有限候选搜索失败不等于全局无解。初始必要条件不满足、当前策略有违约见证、区间界尚不确定分别记录。
- A3 折线基线与 A7–A9 曲线启停模型不是同条件性能排名。A8 比较同一固定 UUV 任务下两套 USV 策略的支援范围和航程成本，不声称最优或能耗更低。
- A9 在相同 2300 m / 25 m / 50 m 与固定 UUV 任务下减少 USV 航程；有限候选的贪心前视改进不等于全局最优，运动时间减少也不等于能耗已验证。
- A10 统一复跑只验收固定版本与声明二维模型，不能代替使用者理解验收、跟踪控制或严格论文原图／原表对齐。
- 真实洋流、能耗、深度、声学、跟踪控制、部署回收和实艇试验不在已验证范围。

## 反馈控制与扰动实验（A11–A13）

控制基线采用自定义的**全驱动二维加速度双积分器与独立航向模型**。东向／北向位置为 p，水相对平面速度为 v，航向为 ψ，转向速度为 r：

- ṗ = v + c，v̇ = a；ψ̇ = r，ṙ = α。
- c 是每个试验预先设定的恒定平面漂流；a、α 在每个控制周期内保持常数，仿真器用解析积分更新实际状态。
- 水平速度方向与航向独立可控，模型允许侧向加速与驻点补偿。**它不满足真实欠驱动船舶的全部运动限制**，不能用来证明实艇可执行性或实际最小转弯半径。
- 常见船舶模型还包括惯性、科氏、阻尼和恢复项，见 [Fossen 官方模型说明](https://www.fossen.biz/html/marineCraftModel.html)。本项目没有识别这些水动力参数，也没有复现原论文 MPC。来源与工程参数属性见 [控制来源说明](control_sources.json)。

控制器使用参考加速度前馈，加上位置比例／积分和地速误差反馈；航向使用角加速度前馈及航向／转向速度反馈。位置和航向按场景加入误差，速度与转向速度理想可知。积分项有显式限幅，平面加速度、角加速度、速度和转向速度均有限幅。增益、执行器余量和误差强度是 [配置](../configs/tracking_control_a11.json) 中的工程设定，不是拟合的真实设备参数。名义条件的毫米级误差属于理想模型的计算结果，不能解释为实艇精度。

参考沿用 A9 的初始位姿、UUV 轨迹／速度、89 个扫描时段和共同任务时间。A12 的初始偏差是明确的实际状态扰动，未替换参考路线；漂流进入实际位置方程，测量偏差进入反馈，实际状态不会重置为参考状态。

### 实际轨迹验收

控制指令保持期间的位置是二次曲线。其相对端点连线的最大偏差以 |a|Δt²/8 外包；轨迹简化的 **0.02 m** 误差也完整计入。所有扫描开启边界均加入时间网格。

- 覆盖：对实际扫描轨迹构造保守内／外足迹，仍以原完整目标作分母；等待和普通转场保持关闭扫描，门槛仍为 99.9%。
- 导航与障碍：整条实际曲线包络需处于原安全导航域，并保留 50 m 原始障碍裕度。
- 平台间距与支援：全任务每个控制区间均有连续距离外包，仍要求 25 m / 2300 m；不是仅检查输出帧。
- 独立审计：使用另一套参考积分、端点平均速度的梯形恒等式、反馈指令复算和中点移动长度包络，再核查原始目标与足迹。认证通过、存在违约见证、界尚不能认证分别记录。

A11 比较 0.25、0.5、1 s 控制更新周期。由于各周期内的模型积分是解析的，这属于**数字控制周期敏感性**，不冒称数值积分器收敛试验。A12 是同一地图与任务下的 7 个确定性工程条件，每条件一次，不作随机总体、显著性或普遍鲁棒性推断。A13 的完成要求全部计算与审计有效，名义基线通过，并保留强干扰违约；不要求把所有强干扰误报为安全。

覆盖数值中的“主流程下界”和“独立审计下界”可能略有不同：主流程对简化误差使用固定 0.02 m 余量，独立审计逐段计算实际简化偏差，可得到更紧的保守包络。两者针对同一条实际轨迹，均需满足 99.9%，不能把下界差异解释为任务或轨迹被替换。
