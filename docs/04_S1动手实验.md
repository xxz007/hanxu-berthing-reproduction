# S1：从单障碍地图到四叉树

## 这一步要弄懂什么

同一张地图可以用64个等大小单元表示，也可以只对障碍附近不断细分。本实验先验证空间表示、位置查询、邻接和线段碰撞，不运行A*。

地图来源：理论窗口的手动练习，属于合成教学算例。它不是论文长滩港地图，不用于表3.3的指标复现。实现为本项目自编，未引入外部算法代码。

## 固定规则

- 地图`[0,8)×[0,8)`，障碍`[3,4)×[3,4)`，x向右、y向上，教学长度单位。
- 根深度0，最大深度3。含正面积障碍且未达最大深度才继续四等分。
- 到达最大深度仍含障碍的叶区域整体记为障碍，即便只有一部分被占据。
- `r`表示根，后续每两位表示一层：`00`左下、`10`右下、`01`左上、`11`右上。页面上的L00等是叶表显示标签，不是另一套树编码。
- 点归属左/下闭、右/上开；x=8或y=8不在地图内。
- 空闲叶共享正长度边界才相邻；角接触不相邻。
- LOS用整条线段与障碍叶的闭矩形相交检查，接触边界也判受阻。位于空闲叶的点仍可能贴着障碍边界，因此“归属空闲”不等于“几何无碰撞”。

邻接实现遍历叶区域，是用于核查的几何参照，复杂度为每次查询O(L)。论文的外缘探测方案尚未实现。LOS使用线段与矩形的解析相交检查，没有实现论文图3.2的采样或平行线方法；本实验用它提供小型矩形地图的几何参照。浮点运算不构成任意几何和真实船体的安全保证。

## 自己运行

在项目根目录执行，所有命令使用项目独立环境：

```bash
.venv/bin/python scripts/check_environment.py
.venv/bin/python scripts/run_s1.py
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -v
```

运行脚本会打印本次新建的outputs目录。打开其中的`index.html`，同时查看`leaves.csv`、`queries.json`、`adjacency.json`和`metrics.json`。每次运行独立保存，不覆盖上一轮。运行脚本不自动执行单元测试；第三条命令单独完成测试。

已有独立环境是Python 3.12.14，以`venv --without-pip`创建，没有安装pip或第三方库。迁移电脑后可以用本机Python3.12重新建立该环境，不复制旧的`.venv/`。
