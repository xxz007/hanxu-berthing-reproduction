# A3：两艘 UUV 分工与 USV 水面支援

本阶段回答：固定 A2 的扫描任务与覆盖目标后，能否让两艘 UUV 分工执行，并让一艘 USV 在声明的水平支援距离内运动，同时通过完整时间区间的平台间距核查？

## 固定输入与边界

- 地图沿用 A1 长滩 NOAA ENC；原始完整目标 **8,767,426.837145586 m²**，SHA-256 `12183e2b7a1ef72109b8b1886ae93f50bc7619d6d7eb05d8927820cbdeda14ea`。
- 输入是已经独立审计的 A2 正式结果：66 条主扫描、20 条补扫，共 86 条任务。允许整条线反向，禁止删去、移动或缩短任务。原始漏扫、重复覆盖与小区分母保留。
- 默认配置固定已保存 A2 的完整结果及来源账本。其他机器重新生成 A2 时，只有三项计算耗时可以变化；`freeze_equivalent_a2_inputs.py` 会先验证其余科学结果、A2 配置、导航图及四份覆盖几何一致，再独占创建一份新的固定配置。原配置和严格运行时哈希检查均保留。
- 规划仍用 A2 最大可达保守格区，原始完整 2.5 m 栅格另作独立碰撞审计。不会清除障碍或在不连通区域间跳跃。
- 两艘 UUV 的任务起点不同。本次时钟从三平台已经部署到各自初始位置后开始；部署、下潜、回收、返港均不计入。等待期间和结束后都显式停留在当前位置。
- UUV 速度 1.5 m/s、USV 移动速度 3 m/s、最小水平间距 25 m、水平支援范围 3000 m，均是本实验工程设定，不能当作实际设备指标。

## 实验流程

1. 给 A2 活动扫描腿编号，逐条保存源腿索引、几何与长度。
2. 按任务中点南北排序，优先保持同一高度的任务组完整。用“扫描长度＋欧氏连接估计”最小化较大的任务负载，选出两个连续任务带。该启发式不保证最优。
3. 各带内按高度与蛇形方向执行；补扫插入对应高度。扫描之间通过 LOS 或 Theta 式 A* 加 LOS 简化连接，连接期间关闭扫描。
4. 额外生成采用同一排序方法的单 UUV 对照，区分任务重排与增加平台数量的影响。原 A2 路线保持原样。
5. 用弧长和固定速度给两条路径赋时。若发现平台靠得过近，在限定窗口内按固定步长延迟后出发的平台；出发前停留也参加核查，无解就报告失败。
6. 在七个任务时刻取两艘 UUV 的位置中点，为 USV 选取附近可达格心。停留锚点距两艘 UUV 的完整路线至少 35 m；锚点间避障连接，并检查允许出发时隙。此设计只模拟几何支援关系。
7. 对所有分段直线运动解析计算平台间距：相对位置平方是二次式，检查区间端点及内部最小值；最大距离检查端点。覆盖完整任务时钟与所有等待，不只检查动画帧。
8. 独立审计任务分配、几何/时间一致性、原始阻塞格碰撞、连续间距和支援范围；四份覆盖几何与 A2 逐字节核对。

## 验收与输出

- 86 个源任务恰好分配一次，分配清单、活动腿与扫描时段三方一致；USV 从不计入扫描。
- 三条完整路径留在原目标内，距原始实体障碍至少 50 m，原始未合并阻塞格逐段碰撞数为 0。
- 全时钟所有平台水平间距不小于 25 m，USV 到每艘 UUV 水平距离不大于 3000 m。
- 覆盖足迹集合不变，保留 A2 的 99.900052% 覆盖和 8762.85 m² 剩余漏扫，不宣称 100%。
- 输出保存配置、源输入/代码 SHA、代码快照、任务分配、几何路线、时间段、独立审计、结果图与可离线打开的 HTML 回放；每次运行写入独立目录。

## 尚不验证

本阶段是二维点平台折线与固定速度时钟，不验证有限转弯半径、加速度、洋流、能耗、控制跟踪、真实扫测物理、UUV 深度和海底净空。水平支援距离也不代表声学通信质量或可用性。原论文严格复现缺口继续保留。
