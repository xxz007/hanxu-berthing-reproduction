# A2：单平台几何覆盖实验约定

问题：在 A1 已固定的真实海图候选水域中，能否生成一条位置连续、避开障碍的单平台搜索路径，并在声明的理想扫描模型下达到至少 99.9% 的覆盖？

初版协议与配置在首轮运行前确定。5 m 全区扫描中心访问明确失败后，做了一次 2.5 m 细化，再在修订版运行前明确下面的“可达扫描中心、完整目标”规则；初版配置、源码及失败日志保留。A1 原始候选面及其孔洞保持不变；本阶段是应用扩展，不是原博士论文新增算法或原图数值复现。

## 固定输入与参数

- 原始目标：A1 候选水域，面积 **8,767,426.837145586 m²**。使用配置中的几何文件 SHA-256 与 A1 来源清单三方核对。
- 原始障碍和A1源配置也固定SHA。原清单的完整SHA作为参考快照保留；重新准备相同输入时，清单中的生成时间与执行代码元数据可变化，但目标、障碍、源配置必须仍逐字节一致，不能把时间戳变化当成科学输入变化。
- 规划格：局部 `[0, 0, 5120, 5120] m`，`2048 × 2048`，单格 `2.5 × 2.5 m`；完整空闲闭格必须位于原始候选面内。首试5m的完整输出保留。
- 扫描中心域：选最大四连通格区作为起点导航域。其他格区仍完整留在原始目标中，必须进入覆盖率、漏扫面积和图件统计；仅不作为当前起点可达的扫描中心，不能据此减少目标分母。
- 保守边界：规划面另做明确的 **1 mm 数值内缩**，用于避免栅格边缘容差；原始任务面不改变，面积分母仍是原始 A1 候选面。
- 传感器模型：理想水平圆形足迹，半径 **50 m**，即扫宽 **100 m**。只在扫描腿开启；连接腿不计扫描。单格区间可形成零长度扫描腿，按一个点足迹处理，不赋予驻留时间。
- 航线：沿局部东西方向，南北间距 **80 m**，地图原点相位 **40 m**。落至最近格心，等距时选较高行，因此2.5m格的实际相位为 **41.25 m**，后续为 121.25 m 等。
- 不包含遮挡、扫频、探测概率、三维地形、深度动力学、真实速度和控制。

100 m 扫宽与 80 m 间距对应相邻平行扫幅宽度的名义重叠 20%；它与“原始目标中被至少两次覆盖的面积占比”是不同定义，后者按实际几何另行统计。

## 路径生成

1. 在起点可达导航域的每条选定扫描行中提取全部连续空闲区间，孔洞两侧分别形成扫描腿。完整候选面的其他区域仍是传感器覆盖目标。
2. 每行按左右方向交替访问这些区间，形成往复搜索顺序。
3. 相邻扫描腿之间先检查整段 LOS；不能直连时使用已有 Theta 式 A*，再作显式 LOS shortcut。连接腿的扫描状态关闭。
4. 将所有扫描足迹裁剪到原始 A1 目标，计算初始覆盖与漏扫。
5. 若未达到 99.9%，按漏扫面从大到小依次选内部代表点，找到最近可达保守格心，选择第一个具有正的精确漏扫面积增益的短扫描腿，再加入所需避障连接。扫描腿最长40m，优先水平，单格宽区间改用竖直段；最多64次，无有效增益或仍未达标时保留剩余漏扫与失败状态。

这是固定方向和贪心补扫的学习基线，不声明扫描方向、访问顺序、路径长度或重复覆盖已达全局最优。所选可达导航域内的无解连接必须报错，不能跳过所请求扫描区间或清除障碍。导航域外的原始目标必须保留，不能缩小目标以提高覆盖率。

5m栅格得到三个分区；2.5m细化将原来425m²的一个小区并入主区，但仍有另一小区和单格分区。原始候选到1m几何内缩仍连通，2m开始分裂，说明存在离散化敏感的细颈。修订后的规则区分平台中心可达性与足迹覆盖范围；小区是否覆盖由真实足迹计算，不据格心距离诊断预先宣布达标。

## 覆盖统计

对每条开启扫描的腿，将线段周围 50 m 的区域及圆形端帽作为理想足迹，裁剪至原始目标。原生几何计算使用每象限 30 段的圆弧近似，足迹略小于理想圆；独立抽查直接使用点到闭线段的解析距离。

| 指标 | 定义 |
| --- | --- |
| 覆盖率 | 所有开启扫描的足迹并集面积 / 原始目标面积 |
| 漏扫率 | 原始目标减去足迹并集的面积 / 原始目标面积 |
| 重复覆盖率 | 被至少两条开启扫描腿覆盖的面积 / 原始目标面积 |
| 累积冗余比例 | 各扫描腿裁剪面积之和减去并集面积，再除以各腿面积之和 |
| 路径长度 | 全部扫描、补扫和连接腿的长度总和 |
| 折线方向变化 | 相邻非零位置线段的航向变化次数，包含连接折角；不表示倒车换挡 |

同一扫描腿即使有多个共线节点也只算一次覆盖。连接腿即使穿过未扫水域也不增加覆盖面积。扫描面积达到多少就报告多少，不能把“栅格内可走面积占比”当成覆盖率。

## 验证关口

- 原始目标指纹与面积保持不变；规划格逐格检查完整闭格包含性。
- 原生几何检查整条路径被原始候选面覆盖，与原始实体障碍的最小间距至少 50 m。
- 路径与分腿顺序一致，连接位置连续，长度可独立重算。
- 独立检测全部实际路径线段与原始未合并阻塞格的闭矩形相交关系，不调用规划树 LOS。
- 固定 10 m 格心网，独立射线法判断原始目标，解析点到线段距离计算扫描次数；目标边界点单列，报告采样面积与原生矢量面积的差异。
- 精确几何覆盖至少 99.9%；剩余漏扫和重复区域保留并绘制。

通过这些关口只说明位置折线与声明的几何覆盖模型通过检查。有限转弯半径、连续曲率、潜器与水面船运动模型、时间协调及跟踪控制仍需后续独立验证。
