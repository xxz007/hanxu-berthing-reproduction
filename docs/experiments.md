# 实验、成果与复跑入口

本文提供实验条件、主要数值及运行入口。完整固定参数在 `configs/`，数值汇总保留在各实验的 `*_summary.json`；数据和脚本生成结果写入调用者指定的独立输出目录。

```bash
python scripts/run_s1.py
```

使用 8×8 合成地图中的单个障碍，检查叶区块、点归属、共边邻接和 LOS。源码见 [quadtree.py](../src/berthing_planner/quadtree.py)，固定结果见 [S1 示例](../reports/baseline/s1/index.html)。这是教学地图，不是论文港口原图。

```bash
python scripts/run_demo.py
```

合成港口示例覆盖搜索、平滑和抵泊姿态接入，输出 HTML、指标与轨迹。固定演示见 [结果索引](../reports/README.md)。

恢复港口图的两类组合结果分别为：通航路径 **4908.3 m**；船艉抵泊 **4142.3 m**，其中倒车 **989.4 m**，方向切换一次。船艉采用显式轴线补充策略，RS 接头不保证全局 G2；参数、地图恢复及平滑限制见 [方法说明](methods.md#paper-alignment)。合成演示与恢复图实验数值不可混用。

## 真实 GSHHG 跨图重规划

使用 GSHHG 2.3.7 粗／细岸线及保守闭格障碍裕度。原路线在细图中穿过 191 个阻塞格，局部替换后为 0；总长由 **481.501 km** 变为 **484.451 km**，只替换原路线中 **23.871 km** 航段。端点为图像近似读数，分辨率和裕度离散条件单独设定。

数据版本、许可与转换见 [GSHHG 来源](r8_data_sources.json)，代码入口为 `scripts/build_gshhg_maps.py` 与 `scripts/run_cross_chart_r8.py`。具体脚本参数以 `--help` 为准。

<a id="a1"></a>
## A1：真实海图与目标区域

使用 NOAA ENC `US5LGBCE` / `US5LGBDE` 固定版本。10.031 km² 不规则任务边界扣除不合格水深、实体障碍及明确排除区后，得到 **8.767426837 km²** 覆盖目标；5 m 水深分区下界和 50 m 障碍裕度为工程设定。

来源与版本见 [海图登记](open_chart_stage_a_sources.json)。`download_open_chart_stage_a.py` 的 `--noaa-cname` 仅为下载请求选项，保持 TLS 校验；不修改全局网络。在线图幅可能更新，下载文件必须通过固定大小和 SHA 校验，不能将不匹配的新文件当作原实验输入。

<a id="a2"></a>
## A2：单平台区域覆盖

理想扫描半径 50 m，行距 80 m，2.5 m 保守格；66 个主扫描与 20 个补扫任务组成连续位置路线，普通连接关闭扫描。完整目标的覆盖率为 **99.900052%**，漏扫约 **8762.85 m²**，重复覆盖约 **24.8615%**。小格区始终留在目标分母内，不将“扫描中心可达域”替代覆盖目标。

定义见 [覆盖实验约定](coverage_a2_protocol.md)，数值见 [A2 汇总](coverage_a2_summary.json)。这是位置折线与理想足迹实验。

<a id="a3"></a>
## A3：多平台分工与折线时钟

保留 A2 的 86 个任务，按 39 / 47 分配给两艘 UUV，USV 负责几何支援。固定速度折线模型中，预部署后的任务时长约 **14.021 h**，最小水平间距 **445 m**，最大支援距离 **2760.385 m**。等待不扫描，覆盖足迹不变。

该模型不含有限转弯半径和加速度；不能直接与曲线启停模型比较任务效率。方法见 [分工实验约定](cooperative_coverage_a3_protocol.md)，数值见 [A3 汇总](cooperative_coverage_a3_summary.json)。

<a id="a4"></a>
## A4：转弯空间与局部启停运动

固定扫描端点并要求只前进、最小转弯半径 20 m 时，168 个必要端点中 40 个存在必要空间冲突。六组局部半径／预留空间试验说明：折线位置可行不自动推出有限半径可行，缩短端点也需要重新核算覆盖。

入口 `scripts/run_motion_sensitivity.py`，结果见 [A4 汇总](motion_feasibility_a4_summary.json)。

<a id="a5"></a>
## A5：覆盖目标与安全导航域

覆盖目标保持 **8.767 km²**，独立安全导航水域为 **17.628 km²**，原 50 m 裕度不变。固定端点的曲线连接从 21/90 增至 47/90；其余失败不能全部解释为全局无解，也未在该试验中生成完整 UUV 路线。

数值见 [A5 汇总](headland_navigation_a5_summary.json)；连接、必要空间证书和端点调整分别由公开脚本核查。

<a id="a6"></a>
## A6：个体连续曲线与按需补扫

联合调整扫描位姿、方向与顺序，保留 86 个原任务；UUV2 的起点和短任务顺序显式改变。UUV1/2 曲线分别长 **75.088 / 92.997 km**，最小转弯半径 20 m；USV 半径 40 m。原语接头停稳，检查个体启停速度。

只开启原 86 个扫描段时，覆盖下界为 **99.8761%**；增加 3 个明确补扫窗口后，下界为 **99.90391756%**，漏扫面积上界约 **8423.96 m²**。补扫沿用既有曲线，其他转场保持关闭扫描。覆盖与方法见 [A6 汇总](joint_coverage_a6_summary.json)。

<a id="a7"></a>
## A7：共同曲线时钟与驻守支援

保持 A6 初始位姿、UUV 曲线与速度律，USV 从原起点转场 **650.58 m / 4.75 min** 后理想驻守。共同任务 **18.825825 h**；最小间距保守下界 **36.200432 m**，最大支援距离保守上界 **2312.242297 m**，满足 25 m / 3000 m。89 个扫描窗口映射到共同时间轴，覆盖保持。

A6 三条独立曲线直接同时出发会有约 5 m 近距与 3225.406 m 超距见证。该对照说明需要重新核查协同条件，不能仅取个体耗时的最大值。

数值见 [A7 汇总](curved_cooperation_a7_summary.json)；回放通过 `build_curved_cooperation_replay.py` 生成到本地，使用解析曲线时钟，安全验收使用完整时间区间证书。

<a id="a8"></a>
## A8：支援范围与移动成本对照

固定 A7 初始条件、UUV 曲线／速度和 89 窗口。面向 2300 m 支援范围设计一个离线分段移动策略：38 个最长 30 min 时间窗，11 次转场，USV 共航行 **10.173334 km**；最大支援距离上界 **2295.476047 m**，最小平台间距下界 **41.995330 m**。任务时长与理想覆盖保持。

原驻守方案在 2300 m 下超距；移动方案满足要求，但 USV 航程是驻守的约 **15.64 倍**，不声称高效或最优。2290 m 下当前两套方案失败不代表任何策略都无解；小于初始必要距离 **2289.562696 m** 的支援范围，在零时刻已经不满足条件。

这是两套固定策略的确定性范围对照，不是 10 份随机独立实验或每个阈值重新优化。数值及分类见 [A8 汇总](support_sensitivity_a8_summary.json)。

<a id="a9"></a>
## A9：同条件减少移动支援航程

固定 A8 三平台初始位姿、UUV 曲线与启停速度、89 个扫描窗口、2300 m 支援范围、25 m 平台间距和 50 m 障碍裕度。38 个时间窗优先核查原地保持；必须移动时，在原候选区域以 25 m 网格筛选驻点，先尝试更长的未来保持时段，再按距离排列候选并比较前进 Dubins 连接的航程。每个未来时段最多取 12 个邻近驻点，跨时段去重；不将这个数量误作所有候选总数上限。

10 s 样点与原语时刻用于候选排除和排序，不能据此接受路线。最终选择仍通过完整时间窗和全任务连续区间证书；独立检查采用另一套圆心与速度积分公式、曲线包络和 GEOS 几何距离。

USV 从 **11 次 / 10.173334 km** 减至 **2 次 / 0.685679 km**，航程减少 **93.2600%**；运动时间从 **4364.18 s** 减至 **351.97 s**。最大支援距离上界 **2295.297927 m**，最小 USV–UUV 间距下界 **38.700304 m**；共同任务 **18.825825 h** 和覆盖下界 **99.90391756%** 保持。UUV–UUV 间距沿用并复核相同 A7 路线证书。

这是有限网格与贪心前视策略对原 A8 的匹配条件改进，不是全局最优、节能或真实驻守控制证明。更少航程也没有减少固定 UUV 任务的完成时间。参数见 [配置](../configs/support_optimization_a9.json)，结果见 [数值汇总](support_optimization_a9_summary.json)。运行、审计和绘图入口分别为 `run_support_optimization.py`、`audit_support_optimization.py`、`plot_support_optimization.py`。

<a id="a10"></a>
## A10：从固定原始海图统一复跑

`run_reproduction.py` 从两份通过大小与 SHA 核验的原始 ENC ZIP 开始，在新目录中重建 A1→A9。包含地图预处理、2.5 m 栅格、单平台覆盖、分工、六组局部转弯核查、安全导航域、个体曲线与补扫、共同时间轴、A8/A9 支援对照，以及独立审计、成果图和测试。没有复用本机旧中间产物，也不自动安装依赖。

```bash
python scripts/run_reproduction.py --archives-dir /path/to/pinned_enc_archives --output-dir outputs/reproduction_run_01
```

`--download` 可代替 `--archives-dir`；需要时加 `--noaa-cname` 使用下载脚本已有的官方域名连接选项。在线文件变化时保留失败记录并停止，不修改固定参数来接纳新版本。成功使用已保存固定快照复跑，并不自动证明其他操作系统、其他依赖版本或当前在线最新海图均可复现。

运行结束后，可进一步核查所有输出哈希、完整步骤顺序、代码／配置版本，以及 A7/A8/A9 的固定科学结果：

```bash
python research_tests/audit_reproduction.py \
  --run-dir outputs/reproduction_run_01 \
  --json-out outputs/reproduction_run_01/independent_acceptance.json
```

固定环境下已完成 35 个步骤、663 份输出哈希核对，204 项核心测试与 113 项科研检查通过；A9 的 159 份派生文件与 PNG 和独立阶段结果一致。[A10 验收汇总](reproduction_a10_summary.json)。

`manifest.json` 保存环境、原始海图哈希、代码／配置哈希和每步命令／日志；`acceptance.json` 检查各阶段审计、完整目标、89 窗口、覆盖下界与距离／裕度门槛，并索引输出哈希。A4/A5 中的历史不可行方案保留为诊断对照；复跑通过不将它们改称完整任务可行，也不表示原论文第三章严格复现或控制闭环完成。

<a id="a11"></a>
## A11：实际反馈轨迹与任务重验

使用受限加速度前馈加反馈控制，独立积分得到实际位置、速度、航向和转向速度。参考固定为 A9，实际扫描覆盖、避障和协同距离重新计算。0.25、0.5、1 s 三种控制周期均通过名义条件核查；0.5 s 时最大位置误差约 **1.06 mm**，这是理想测量与全驱动简化模型内的数值结果，不代表实艇精度。

控制模型允许独立侧向加速，未建立欠驱动船舶水动力学，也不是论文 MPC。门槛与模型说明见 [控制方法](methods.md#closed-loop)，数据见 [A11 汇总](tracking_control_a11_summary.json)。入口为 `run_tracking_control.py` 与 `audit_tracking_control.py`。

<a id="a12"></a>
## A12：预登记扰动与测量误差对照

地图、参考、增益、执行器上限、89 个扫描时段、99.9% 覆盖和 50 m / 25 m / 2300 m 门槛保持。7 个确定性条件为：名义、初始偏差、0.05 m/s 东向漂流、0.1 m 位置偏差叠加 0.02 m 周期测量误差、组合误差、5 m 位置偏差、超速度补偿能力的漂流。参数为工程测试设定，不是当地实测海流或设备规格。

前 5 个条件通过独立轨迹核查；5 m 测量偏差与超速度漂流存在违约见证。前者覆盖低于 99.9% 门槛，后者同时出现大幅跟踪偏差与超支援范围。失败记录保留，不改变门槛或删除条件来达标。每条件只有一次确定性仿真，不作统计显著性推断。

条件与数值见 [A12 汇总](tracking_robustness_a12_summary.json)；入口 `run_tracking_robustness.py`，名义条件复用已审计的 A11 输出，避免把它重复计作独立实验。

<a id="a13"></a>
## A13：原始海图到闭环对照的统一入口

保留原 A10 入口，另提供扩展入口：

```bash
python scripts/run_closed_loop_reproduction.py \
  --archives-dir /path/to/pinned_enc_archives \
  --output-dir outputs/closed_loop_run_01
```

也可用 `--download` 代替 `--archives-dir`，必要时加 `--noaa-cname`。沿用 README 的既有科研环境，不自动安装依赖；输出目录必须不存在。

入口在新目录先执行 A1→A9 的原 A10 流程，再顺序核查 A11 三种周期、A12 七条件与图件，并自动执行 A13 产物核对。结果分别保存在 `planning/`、`a11/`、`a12/`、`figures/`，`actual_tracking_replay.html` 提供实际闭环轨迹的离线回放；顶层编排包含对规划子流程的调用，不将两种步骤计数简单相加。顶层 `acceptance.json` 和 `independent_acceptance.json` 记录范围与验收。`all_registered_conditions_safe` 为 false 是保留强干扰失败的正确结果，不应与运行／审计失败混淆。

```bash
python research_tests/audit_closed_loop_reproduction.py \
  --run-dir outputs/closed_loop_run_01 \
  --json-out outputs/closed_loop_run_01/recheck.json
```

干净副本复跑已通过 35 步规划子流程、11 步顶层编排、786 份输出哈希核对，以及 209 核心 / 121 科研检查。9 次实际仿真的 45 份派生文件及两张 PNG 复现一致。[A13 验收数值](closed_loop_a13_summary.json)。

这一入口验收的是声明替代模型下的规划—反馈仿真与误差对照，不代替原论文严格复现、实艇验证或个人／导师理解验收。
